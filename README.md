# 👑 Game of Thrones: The Chronicles of Westeros

An immersive, highly animated Game of Thrones interactive web application built with **React**, **Vite**, and **GSAP (GreenSock Animation Platform)**. Experience the journey from the Wall of Winterfell to the Iron Throne of King's Landing, and explore the histories and sigils of the great noble houses of Westeros.

Created and maintained by **[Himavanth97](https://github.com/Himavanth97)**.

---

## ✦ Key Features

- **Cinematic Scrolling**: Seamless video scrubbing driven by scroll speed using advanced GSAP ScrollTrigger techniques.
- **Interactive Chronicles**: Dive into the lore of the Seven Kingdoms through a responsive and animated timeline chapter interface.
- **Interactive Noble Houses**: Explore the 3D-tilting cards of the great houses (Stark, Lannister, Targaryen, Baratheon, Greyjoy, and Tyrell), complete with hover reveals of their seat, words, and histories.
- **Atmospheric Visuals**: Elegant corner ornaments, runic progress bars, custom loading screens, and a subtle film grain effect for a premium fantasy aesthetic.

---

## ⚒ Technologies Used

* **Frontend**: React 19, Vite
* **Animations**: GSAP (GreenSock), ScrollTrigger
* **Styling**: Modern CSS with CSS Custom Properties (Variables)
* **Icons & Fonts**: Custom SVGs & Google Fonts (Cinzel, Inter)

## 🚀 Getting Started

To run the application locally:

### 1. Install Dependencies
```bash
cd vite-project
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

### 3. Open in Browser
Visit [http://localhost:5173](http://localhost:5173) to experience the app.
